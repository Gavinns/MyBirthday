# 🎉 HappyBirthday

Web app untuk membuat ucapan ulang tahun custom  masukin nama, foto, dan pesan spesial, langsung jadi halaman ucapan ulang tahun yang bisa dibagikan ke someone !

## ✨ Fitur

- Custom nama penerima ucapan
- Upload/tampilkan foto personal
- Pesan ucapan yang bisa disesuaikan
- Tampilan modern & responsive
- Dibangun dengan komponen React yang reusable

## 🛠️ Tech Stack

- **React** + **TypeScript**
- **Vite** — build tool & dev server
- **ESLint** — linting
- CSS untuk styling

## 📁 Struktur Project

```
HappyBirthday/
```

## 🚀 Instalasi & Menjalankan Project

1. Clone repository ini
   ```bash
   git clone https://github.com/username/HappyBirthday.git
   cd HappyBirthday
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Jalankan development server
   ```bash
   npm run dev
   ```

4. Buka `http://localhost:5173` di browser

## 📦 Build untuk Production

```bash
npm run build
```

Hasil build akan ada di folder `dist/`.

Project ini bebas digunakan untuk keperluan pribadi maupun pembelajaran.
